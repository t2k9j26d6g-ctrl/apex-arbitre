APEX V1.9 · SYNCHRONISATION AUTOMATIQUE

Synchronisation multi-appareils

APEX synchronise désormais automatiquement les données après connexion. Les commandes manuelles restent disponibles comme solution de secours et de contrôle.

1 · Connexion APEX

Non connecté

Le mot de passe n’est jamais stocké dans le code APEX. La session Supabase est conservée localement par le navigateur après connexion.

Compte connecté—
Profil non lu.

2 · Test RLS + écriture/lecture

À tester

APEX écrit uniquement un marqueur technique dans settings.settings_data, puis le relit. Tes check-ins, séances et décisions locales ne sont pas envoyés.

Connecte-toi d’abord.

3 · Cet appareil → Cloud

À synchroniser
🔒 Envoi non destructif

APEX crée une copie de sécurité locale puis envoie les données de cet appareil vers Supabase. apex_v1_data reste présent.

Le bouton sera disponible après connexion et validation du test sécurisé.

4 · Cloud → Cet appareil

À tester

À utiliser sur un nouvel appareil après connexion. APEX lit tes check-ins, débriefs et planning depuis Supabase, crée d’abord une sauvegarde locale de sécurité, puis reconstruit apex_v1_data.

☁️ Restauration contrôlée

Les données Mental/TOP locales éventuellement déjà présentes sur cet appareil sont conservées. Seuls les blocs synchronisés (check-ins, décisions, séances/débriefs, planning et réglages principaux) sont reconstruits depuis le cloud.

Connecte-toi d’abord.

5 · Synchronisation automatique

Initialisation

Quand elle est activée, APEX envoie automatiquement une modification locale vers Supabase puis vérifie le cloud au retour dans l’application. En cas de coupure réseau, la modification reste locale et repart dès que la connexion revient.
